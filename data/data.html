DATA, DATASET & DATABASE

Mengenal dasar-dasar data dalam dunia teknologi dan pemrograman.

1. Data

Data adalah sekumpulan fakta atau informasi yang dapat berupa angka, teks, gambar, suara, maupun bentuk lainnya. Data dapat digunakan untuk memberikan informasi, melakukan analisis, dan membantu dalam mengambil keputusan.

Contoh Data:
  • Nama siswa: Vito
  • Kelas: XII PPLG A
  • Umur: 17 tahun
  • No. Telp: 1234567890

2. Dataset

Dataset adalah kumpulan data yang sudah dikelompokkan dan disusun dalam suatu bentuk tertentu sehingga lebih mudah untuk dibaca, digunakan, dan dianalisis.

Contoh Dataset:
No Nama Kelas Nilai
1 Naura XII PPLG A 90
2 Andravito XII PPLG A 88
3 Zikhal XII PPLG A 85

Tabel tersebut disebut dataset karena berisi kumpulan data siswa yang disusun secara terstruktur.

3. Database

Database adalah tempat untuk menyimpan, mengatur, dan mengelola kumpulan data secara terstruktur sehingga data dapat dengan mudah dicari, ditambahkan, diubah, maupun dihapus.

Contoh Database:

Dalam sebuah sistem sekolah, database dapat digunakan untuk menyimpan:

  • Data siswa
  • Data guru
  • Data kelas
  • Data nilai
  • Data mata pelajaran
Contoh tabel dalam database:
ID Nama Siswa Kelas NISN
1 Naura XII PPLG A 1123426
2 Andravito XII PPLG A 862176321
3 Zikhal XII PPLG A 625173521

Hubungan Data, Dataset, dan Database

Ketiga istilah tersebut saling berhubungan. Data merupakan fakta atau informasi dasar. Beberapa data dapat dikumpulkan menjadi sebuah dataset. Data dan dataset kemudian dapat disimpan serta dikelola menggunakan database.
