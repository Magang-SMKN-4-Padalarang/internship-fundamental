TENTANG WEBSITE INI

Website ini dibuat untuk memenuhi tugas selama Praktik Kerja Lapangan (PKL) di Pt Scola. Website ini berisi kumpulan profil siswa yang sedang menjalani program magang, sebagai media perkenalan diri secara digital.

Proyek ini dikerjakan menggunakan HTML, CSS, JavaScript, dan Bootstrap, dengan tujuan untuk melatih kemampuan dalam membangun website yang rapi, responsif, dan mudah digunakan.
